# USTC WLT

`ustcwlt` is a command-line tool to log in to USTC WLT.

## Installation

```bash
pip install ustcwlt
```

## Usage

```bash
ustcwlt --username <username> --password <password>
```

You can also set environment variables:
```bash
export USTCWLT_USERNAME=<username>
export USTCWLT_PASSWORD=<password>
ustcwlt
```
